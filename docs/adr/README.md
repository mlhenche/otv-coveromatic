# Architecture Decision Records

Registro de decisiones de arquitectura: **qué** se decidió y, sobre todo,
**por qué**. Cada ADR es inmutable una vez aceptado; si una decisión cambia, se
escribe un ADR nuevo que reemplaza al anterior (y se marca el viejo como
"Reemplazado por").

Para crear uno, copia `template.md` con el siguiente número correlativo.
